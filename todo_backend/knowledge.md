# To-Do List Backend Knowledge

1. Built with FastAPI for RESTful task management APIs.
2. Uses SQLite for persistent data storage.
3. CRUD operations: create, read, update, delete tasks.
4. Tasks have completion status (complete/incomplete).
5. API endpoints return JSON.
6. Authentication is not enabled in this version.
7. Designed for integration with a React frontend.
8. All endpoints documented with OpenAPI/Swagger support.
9. Database migrations handled manually.
10. For questions, see project README.md.
